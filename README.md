# Face Detection with GUI Dashboard

## Advanced Face Detection: Utilizes DNN-based and cascade classifiers for robust detection across multiple orientations (frontal, profile, tilted) with real-time quality assessment (blur, occlusion, lighting).

## Multi-Person Recognition: Supports simultaneous recognition of multiple individuals with adaptive thresholding and quality-weighted training.

## Comprehensive Analytics: Includes detailed quality metrics, database logging, and a GUI for real-time monitoring and analysis.

## Enhanced GUI Dashboard: Offers intuitive controls for data collection, model training, live recognition, and quality analysis.
